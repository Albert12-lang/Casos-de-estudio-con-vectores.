# Casos-de-estudio-con-vectores.

## Introducción.
En la actividad de los tres casos:
En el primer caso se va a analizar el valor y el porcentaje de cada categoría de una tienda, saber cuáles de esas categorías llegan hacer críticas (menos ventas) y saber cómo ir mejorando esa categoría. 
En el segundo caso las especialidades de una clínica dental es tener ordenado cada cita por especialidad también reconocer cual es la especialidad crítica (menos citas) e ir tomando una decisión sobre ese problema.
En el tercer caso se analizaron los envíos de mensajería de cada zona geográfica, esto nos permite obtener la información que será crucial en ir tomando decisiones si en alguna de las zonas son críticas (poca distribución de mensajería)
Se van a ir utilizando vectores y estructuras repetitivas para una elaboración eficiente del código. 

## Objetivos.
Usar ciclo ‘para’ para tener una reducción del código y poder recorrer vectores de manera ordenada y automática.
Usar dos vectores que nos ayuden a ir separando cada variable y valor de las variables.
Calcular cada variable de cada caso.
Convertir los valores de cada uno de las variables a porcentajes para ver cuales superaron y cuáles no superaron el promedio de cada caso.

## Desarrollo. 
Se utilizará un vector que almacenará los nombres de cada variable y otro que contiene los valores de las variables, mediante un ciclo ‘para’, se recorrerá los vectores para poder calcular el total de cada uno de las variables con su respectiva cantidad permitiendo obtener el promedio general de cada variable, después se van a ir comparando los datos con cada caso para determinar cuáles superaron el promedio y cuáles van a presentar una actividad menor. El uso de los vectores permitió organizar la información de forma estructural y facilitando su procesamiento.

## Conclusión.
El análisis permitirá conocer el comportamiento de cada variable en sus respectivos casos y obtener información importante para ir mejorando el respectivo problema de los casos. El uso de vectores y ciclos simplificó el manejo de los datos y permitió realizar cálculos de forma rápida y ordenada. 
La identificación de las variables con baja actividad proporcionando información que ayudará para comenzar a planificar estrategias o mejoramiento en cada sección de los casos.
